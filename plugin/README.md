# Design Ops – Processo UX

Plugin del team UX/UI Design. Porta un progetto dalla richiesta alla consegna di un file solido alla UI: l'assistente esegue il lavoro ripetitivo, il designer approva ai controlli.

**Documentazione, domande frequenti e ricerca:** {{SITE_URL}}

## Installazione
1. Rimuovi le skill installate singolarmente: se restano, si attivano due volte.
2. *Customize → Plugins → Add → Upload plugin* e scegli lo zip.
3. Il plugin si carica nel task successivo; se non compare, riavvia l'app.

## Comandi
`Avvia` · `Procedi` · `Stato` · `Aggiorna` · `Annota`, come prima parola del messaggio o come `/design-ops:avvia`, `/design-ops:procedi`, `/design-ops:stato`, `/design-ops:aggiorna`, `/design-ops:annota`.
