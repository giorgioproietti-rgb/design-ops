# Siti per il benchmark – link ricorrenti

Elenco vivo. Aggiungi una riga per sito. Una riga = un sito o una pagina.
Usato in Fase 3 (benchmark): Flusso 2 parte da qui, poi aggiunge solo ciò che il problema richiede.
Usato in Fase 2 (ricerca web): sezione "Ricerca e dati di mercato".

## Come aggiungere un link

- Una riga per sito, nella tabella giusta.
- Colonne: Sito, URL, Paese/lingua, Perché, Aree utili, Accesso.
- Aree utili: onboarding, paywall, TYP, funnel, home, articolo, app, newsletter, ecc.
- Accesso: `pubblico`, `login`, `abbonamento`. Login/abbonamento → serve screenshot dell'utente.
- Verbatim: URL completi, nomi come si scrivono sul sito.
- Data di verifica in `Note` se il sito cambia spesso.
