# Design Ops

Repository del plugin **Design Ops** del team UX/UI Design, della sua documentazione e del sito che la pubblica.

- `plugin/`: solo le istruzioni che si distribuiscono (manifest, skill, comandi).
- `docs/`: documentazione, che diventa il sito.
- `site/`, `worker/`: generatore del sito e servizio delle risposte intelligenti.
- `scripts/`: rilascio e controlli.

Per mantenere il repository: `docs/manutenzione.md`. Per pubblicare il sito: `docs/setup-sito.md`.
